# Aashaa Anant

> A digital platform for Aashaa Anant, a youth-led social service initiative focused on community service, education, environmental action, animal welfare, and social awareness.

## About

Aashaa Anant is a youth-led social service initiative dedicated to creating meaningful impact through compassion, community service, education, environmental action, animal welfare, and social awareness.

This project aims to provide a centralized digital platform for the organization, including a public website, volunteer registration, and administrative management.

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Data JPA
- Maven
- Spring Security

### Database
- MySQL

### Frontend
- React
- Vite

### Tools
- Git & GitHub
- Postman
- MySQL Workbench

## Core Features

- Organization website
- Volunteer registration
- Admin dashboard
- Volunteer application management
- Notices and announcements
- Gallery and media management
- Dynamic organization statistics
